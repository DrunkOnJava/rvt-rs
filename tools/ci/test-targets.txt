# Which tests/*.rs targets CI and tools/check-local.sh run, and why.
#
# Unit tests are banned in this repository (the maintainer's standing
# directive, 2026-09-23): no new ones, and none run in CI or the local gate.
# What runs is verification against real Revit files, end-to-end runs of the
# built CLIs, and contract checks that keep published claims honest. Every
# tests/*.rs target must appear here exactly once, so a new target cannot
# silently run or silently skip; tools/ci/verify-real-files.sh fails when one
# is missing.
#
# Format: <class> <target> [skip=<test name substring>,...]
#   real      reads real Revit files from the corpora and checks what the
#             reader or exporter gives against the file or Revit's own export
#   cli       runs the built binaries end to end
#   contract  checks a published claim (support matrix, binary inventory,
#             witness verdicts, JSON schemas, field-type coverage) against
#             the code and artifacts
#   unit      synthetic-only, property or fuzz-regression tests: kept as
#             source, not run
#
# `skip=` leaves out the synthetic-fixture tests inside a real-file target.
