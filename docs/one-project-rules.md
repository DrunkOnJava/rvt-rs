# Rules that rest on one project

This page lists the rules rvt-rs ships whose evidence, when the report that
introduced them was written, came from one project: one building, however many
saves, disciplines or variants of it were read. It answers the question of
[#1636](https://github.com/DrunkOnJava/rvt-rs/issues/1636): before 1.0, which
second models would test the most of what ships today.

A rule on this list is not known to be wrong. It is known to be measured on one
building, so a second building that holds the same case could show it to be
narrower than it is written. [RE-402](../reports/element-framing/RE-402-second-project-first-measurement.md)
is the first such measurement: of the 15 census lines it read on the BIM4LCA
housing, 5 held and 9 did not.

## How it was made

Every report under `reports/element-framing/` was read for each rule it ships
and for what it says that rule's evidence is (census of 2026-11-14, at
`0ce6c5d6`). A rule is listed where its report says in words that the evidence
is one project, or where the evidence it quotes is one model only ("no, it
names this model only" below). Each row's quote was then checked against the
tree, and each rule against what was written since: a later report, the docs or
the code's own comments that measure it on another project, or withdraw it.
The maintainer checked the quotes behind every verdict that moved a rule off
this list, re-read by hand those not found word for word, checked every rule
left on it against [RE-402](../reports/element-framing/RE-402-second-project-first-measurement.md)
and [RE-405](../reports/element-framing/RE-405-wall-box-is-the-solid.md),
and changed 14 verdicts. The rules measured on another project since are
listed at the end in three parts, with the text that says so: those that were
wrong there and are still open, which are rules to fix or narrow before 1.0,
each with its issue; those that were wrong there and have been repaired or
narrowed since; and those that held.
A rule measured on a second building and wrong there is not settled by having
been measured; it is the clearest case for a fix.

"Its words" is the report's own text. A dash there means the quote was not
found word for word; the report's link holds the claim. The code column names
only identifiers that exist in `src/`.

this machine and not in CI. The held-out models leave the runner as counts
only. A second, redistributable project with Revit's own IFC4 export, saved by
Revit 2024 or 2025 and holding curtain walls, curved walls, stairs and MEP
runs, would test the largest share of the rules below.
